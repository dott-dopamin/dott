# DOTT 예약/보유리스트 사이트

구성
- `index.html` 예약현황 + 오늘 일정 + 공지
- `boardgames.html` 보드게임 리스트
- `murder.html` 머더미스터리 리스트
- `deduction.html` 추리게임 리스트
- `admin.html` 일정/공지/3개 리스트/메인 문구 통합 관리자
- `supabase.sql` 처음 설치할 때 사용하는 전체 DB/RLS/Storage 스크립트
- `add-site-settings.sql` 이미 DB 설치를 마친 경우 메인 문구 편집 기능만 추가하는 패치

## 이미 Supabase DB 설치를 끝낸 경우
이번 버전에서는 관리자 페이지에서 메인 화면 문구를 바꿀 수 있습니다.
기존 일정/공지/게임 데이터는 건드리지 않고 아래만 한 번 실행하세요.

1. Supabase > SQL Editor > New query
2. `add-site-settings.sql` 전체 복사
3. Run
4. 업데이트된 사이트 파일로 교체
5. `admin.html` > 관리자 설정 > 메인 화면 문구에서 수정

## 처음 설치하는 경우
1. Supabase 프로젝트 > SQL Editor > New query
2. `supabase.sql` 전체 내용을 붙여넣고 Run
3. Authentication > Users 에서 관리자 계정 생성
4. 공개 Sign ups는 꺼두는 것을 권장
5. `admin.html` 로그인 후 일정/공지/게임/메인 문구 관리

## 관리자 기능
- 일정 추가/수정/삭제
- 공지 추가/수정/삭제
- 보드게임/머더미스터리/추리게임 추가/수정/삭제
- 메인 예약현황 상단의 작은 문구/큰 제목/설명 문구 수정
- 관리자 자신의 비밀번호 변경

## 글꼴
메인 큰 제목, 카드 제목, 관리자 제목까지 메뉴와 같은 산세리프 계열 글꼴로 통일했습니다.

## GitHub Pages 배포
1. GitHub public repository 생성
2. 이 폴더 안의 파일 전체를 저장소 최상단에 업로드
3. Settings > Pages
4. Deploy from a branch
5. Branch `main`, Folder `/ (root)` > Save

## 2026-09-21 요청사항 반영 (v3)
- 일정 시간은 10분 단위(00/10/20/30/40/50) 선택만 가능
- 일정의 `담당자` 표기를 `벙주`로 변경
- 일정 상태는 `예약 / 취소` 두 가지로 단순화
- 취소 일정은 공개 캘린더/오늘 일정에서 줄긋기 + `취소` 배지로 표시
- 캘린더 일정은 2줄(시간·제목 / 인원·벙주) 표시, 글자 검정, 카테고리색은 배경에만 적용
- 일정이 있는 날짜 칸의 별도 배경 강조 제거
- 공지 내용은 입력한 줄바꿈을 그대로 공개 화면에 표시
- 보드게임/머더미스터리/추리게임 공개 페이지에 `갤러리 / 리스트` 보기 전환 추가

기존 Supabase 테이블 구조 변경은 필요 없습니다. 이전 상태값(`진행`, `마감`)은 화면에서 `예약`으로 처리됩니다.


## 캘린더 가독성 추가 조정
- 카테고리 일정 카드 배경색을 이전보다 약 30% 더 옅게 조정
- 시간/일정명 굵은 글씨 제거(일반 굵기)
- DB/SQL 변경 없음


## v4 수정사항
- 메인 상단 작은 문구 배경색을 더 옅게 조정
- 메인 설명 문구 폰트 축소
- 공지사항을 작성 순서(오래된 글 → 새 글)대로 표시해 새 글이 맨 아래에 추가되도록 변경
- 보유목록 갤러리 PC 기준 한 줄 5개
- 카테고리 색상: 보드게임=옐로우 / 머더미스터리=기존 오렌지 / 추리게임=그린 / 기타=기존 유지
- DB 스키마 변경 없음 (추가 SQL 실행 불필요)


## 추가 수정
- 하단 `© 2026 DOTT` 표기를 `© 2026 도파민`으로 변경했습니다.
- 관리자 설정에서 보드게임/머더미스터리/추리게임 목록 페이지의 설명 문구를 각각 수정할 수 있습니다.
- 기존 Supabase 프로젝트는 `add-catalog-descriptions.sql`을 SQL Editor에서 1회 실행하세요. 기존 데이터는 삭제되지 않습니다.

## v6 변경사항
- 보드게임/머더미스터리/추리게임 공개 페이지에서 갤러리 보기를 제거하고 단일 리스트 표 형식으로 통일했습니다.
- 각 게임은 게임명/인원/시간/난이도/장르/위치/상태/소유주가 한 줄에 표시됩니다. 작은 화면에서는 가로 스크롤로 볼 수 있습니다.
- 관리자 항목 추가/수정에서 이미지 파일 및 이미지 URL 입력을 제거했습니다. 기존 DB의 image_url 데이터는 삭제하지 않으며 화면에서 사용하지 않습니다.
- 각 보유목록 관리자 탭 상단에서 리스트 제목 아래 설명 문구를 바로 수정할 수 있습니다.
- v5의 add-catalog-descriptions.sql을 이미 실행했다면 추가 SQL 실행은 필요 없습니다.

## v11 변경사항
- 캘린더 일요일 날짜는 빨강, 토요일 날짜는 파랑으로 표시합니다.
- 보드게임/머더미스터리/추리게임 목록과 관리자 입력에서 위치 항목을 제거했습니다.
- 위치 컬럼 제거에 맞춰 PC/모바일 게임 목록 열 너비를 다시 조정했습니다.
- DB의 기존 location 컬럼은 삭제하지 않아 별도 SQL 실행이 필요 없습니다.

- v12: 위치 제거 후 게임 리스트 7개 컬럼 간격/정렬 재조정 (PC/모바일)
