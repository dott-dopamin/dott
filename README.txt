DOTT 최신 기준본
================
정리일: 2026-10-04
용도: GitHub 저장소를 비운 뒤 이 폴더 내용을 그대로 다시 업로드하는 클린 기준본

현재 포함 기능
- 공개 예약 캘린더
- 관리자 일정/출석/공지 관리
- 보드게임/머더미스터리/추리게임 공통 구조
- 모바일/PC 게임 목록
- 게임 상태 5종: 도트/공방/대여중/보유/분실
- 대여관리대장 + 대여자/대여일/반납완료
- QR 셀프 게임 대여 페이지
- 보드게임 '오늘 뭐하지?' 추천기
- 머더미스터리 공지 팝업
- 출석 2개월 경과 14일 전 경고 표시
- 회원 상태와 무관한 자유 메모
- 회비 개별/일괄 납부 처리
- 회계장부 자동 연동
- 월 마감/월별 보고서
- 회계 영수증 여러 장 첨부 + 1번/2번/3번 보기
- 관리자 모바일 게임3종/대여/회비/회계 전체보기
- iPhone 일정/회원 팝업 날짜 input 폭/높이 보정 및 자동확대 방지
- '오늘 뭐하지?' 버튼 높이는 전체 N개 pill에 맞추고 폰트 유지 + 가로폭 자동

GitHub 재업로드 방법
1. 기존 GitHub 저장소의 루트 파일을 삭제
2. 이 ZIP의 압축을 풀고 내부 파일/폴더를 저장소 루트에 전부 업로드
3. Commit changes
4. GitHub Pages 배포가 끝난 뒤 브라우저 새로고침

주의
- Supabase 데이터는 GitHub 파일 삭제와 무관하므로 그대로 유지됩니다.
- 기존 Supabase SQL이 이미 적용되어 있다면 다시 실행할 필요 없습니다.
- database-history 폴더는 SQL 변경 이력 보관용입니다. 임의 재실행하지 마세요.
