DOTT 회비 · 회계 추가본
======================

추가된 관리자 메뉴
- 회비 · 회계 > 회비 현황
- 회비 · 회계 > 회계장부
- 회비 · 회계 > 월별 보고서

핵심 동작
- 회원 목록은 기존 출석관리 attendance_members를 그대로 사용합니다.
- 회비 납부완료 처리 시 회원별로 회계장부 1건씩 자동 생성됩니다.
- 여러 명을 처리하더라도 합산 장부 행을 만들지 않는 DB 구조입니다.
- 회계 구분: 회비 / 유지비 / 기타 / 미지급금 / 이자수익
- 미지급금은 발생/지급으로 기록하며 현금 잔액에는 지급 시점만 반영됩니다.
- 지출/미지급금 증빙은 JPG/PNG/PDF를 비공개 Storage에 저장합니다.
- 로그인한 관리자만 영수증을 보고 다운로드할 수 있습니다.
- 월 마감 후 해당 월의 회비/회계 수정은 UI뿐 아니라 DB 트리거에서도 차단됩니다.
- 관리자만 마감 해제 후 다시 수정할 수 있습니다.
- PDF 생성 버튼은 브라우저 인쇄(PDF 저장)를 사용하며 마감 완료 월에 표시됩니다.

필수 1회 작업
1. Supabase > SQL Editor > New query
2. database-history/add-accounting.sql 전체 복사/붙여넣기
3. Run
4. GitHub Pages에는 이 백업 ZIP의 루트 파일들을 기존 사이트 루트에 덮어쓰기

주의
- SQL을 실행하기 전에는 관리자 페이지 상단에 회비/회계/월 마감 데이터를 불러오지 못했다는 경고가 표시될 수 있습니다.
- 기존 일정/공지/출석/게임 테이블은 삭제하거나 초기화하지 않습니다.
